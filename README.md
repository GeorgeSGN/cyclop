# Cyclop

Чёлка MacBook как рабочий инструмент. Панель раскрывается при наведении курсора
на чёлку и складывается, когда курсор уходит.

Урезанная сборка [akalikbergenov/cyclop](https://github.com/akalikbergenov/cyclop)
под свои задачи: оставлены полка со скриншотами, буфер обмена, закреплённые
заготовки и офлайн-перевод. Вырезаны плеер, календарь и заметки.

| Вкладка | Что делает |
|---|---|
| **Полка** | Файлы затаскиваются в чёлку и лежат там, пока не понадобятся; карточку можно вытащить обратно куда угодно. Клик выделяет карточку, ⌘-клик — несколько, дальше группа тащится целиком. Скриншот, снятый в буфер, сохраняется файлом и попадает сюда же — включая снятый на iPhone, если скопировать его там |
| **Буфер** | Последние 40 копий; клик возвращает запись в буфер обмена |
| **Заготовки** | Список того, что надоело перенабирать: адрес, телефон, почта. Добавляются кнопкой в панели, удаляются крестиком; клик кладёт текст в буфер. Тот же список лежит в `~/Library/Application Support/Cyclop/snippets.json` и правится прямо там |
| **Перевод** | Слева набираешь, справа появляется перевод — сам, офлайн, средствами самой macOS. Английский идёт в русский, русский в английский; направление определяется по алфавиту. Языковой пакет macOS не ставит заранее, в первый раз его надо скачать: Системные настройки → Основные → Язык и регион → «Языки перевода…» |

## Чем отличается от оригинала

- **Ни одного разрешения.** Вместе с календарём ушёл EventKit — единственное, что
  просило доступ. Приложению теперь не нужно ничего.
- **Никаких приватных фреймворков.** Плеер держался на приватном
  `MediaRemote.framework`, к которому приложение добиралось через dylib,
  загруженный в `/usr/bin/perl` (единственный доверенный демоном путь начиная с
  macOS 15.4). Всё это выкинуто вместе с плеером — и вместе с риском, что Apple
  однажды закроет этот маршрут или уберёт perl из системы.
- **Одна колонка иконок.** Четыре вкладки помещаются в левый рейл, правый больше
  не нужен.
- **Стартует на полке**, а не на плеере.

## Требования

- macOS 15 или новее (перевод работает на `Translation.framework`)
- Swift 6 (полный Xcode не нужен, хватает Command Line Tools)

Работает и на маках без чёлки: панель тогда считает чёлкой область 180 × 24 pt
в верхнем центре экрана.

## Сборка

```bash
./Scripts/bundle.sh          # swift build + сборка .app + ad-hoc подпись
open build/Cyclop.app
```

Иконка в меню-баре открывает панель, включает запуск при входе и выходит из
приложения.

## Где лежат данные

- Скриншоты из буфера — `~/Pictures/Cyclop/`, ничего не удаляется само.
  Очистить — из меню в меню-баре, там же показан размер папки
- Заготовки — `~/Library/Application Support/Cyclop/snippets.json`

## Обновления из upstream

```bash
git fetch upstream
git merge upstream/main
```

Конфликты ожидаемы в `NotchViewModel.swift`, `NotchContentView.swift` и
`Scripts/bundle.sh` — именно там вырезаны вкладки.
